# Verde House Productions

Verde House Productions is a full-stack content monetization and distribution system. It turns long-form video into short-form clips, posts them automatically across social platforms, and runs a consumer app where users get paid to post branded content — all managed from a central dashboard.

## Components

| Folder | Description |
|---|---|
| `clip-bot/` | AI clip generator — takes long-form video, outputs TikTok/Reels/Shorts-ready clips |
| `auto-poster/` | n8n automation — watches a folder and posts clips to TikTok, Instagram, and YouTube Shorts |
| `consumer-app/` | Earn-to-post web app — users browse campaigns, post opinions, get verified, get paid |
| `verde-dashboard/` | Command center — manages campaigns, clients, clip pipelines, and analytics |
| `docs/` | Documentation and notes for the full system |
