# /stopslop — Anti-Slop Mode

Enforce quality standards on all code and copy output:
- No Lorem Ipsum, placeholder names, or dummy data — use realistic Verde House content
- No generic variable names (data, result, temp, foo)
- No TODO comments without a linked task
- No console.log left in production code
- No copy-paste boilerplate without understanding it
- Call out any "cargo cult" code that doesn't serve a purpose
- Every function must have a single, clear responsibility
- If something is sloppy, say so and rewrite it
