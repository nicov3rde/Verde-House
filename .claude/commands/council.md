# /council — Multi-Perspective Review

Before finalizing any major decision (architecture, feature, API design), consult The Council:

**The Pragmatist** — Will this actually ship? What's the simplest version that works?
**The Security Auditor** — What are the attack vectors? Auth gaps? Data exposure risks?
**The UX Advocate** — Would a real user understand this? Where will they get confused?
**The Scalability Engineer** — Will this break at 10k users? 100k? What needs to change?
**The Product Manager** — Does this serve Verde House's core mission? Should we build it at all?

Present all five perspectives, then give a final recommendation.
